# Business Management 101

This repository hosts the course materials for Business Management 101. It is designed to provide a comprehensive and interactive learning experience for students, and to facilitate collaboration among instructors, administrators, and advisors.

## For Students

Welcome to Business Management 101! This course will provide you with a foundational understanding of the essential principles of business management.

You can access the course website here: [https://businessmanagement101.github.io](https://businessmanagement101.github.io)

The website contains the syllabus, schedule, assignments, and all other course materials.

## For Collaborators

We welcome contributions and feedback from instructors, administrators, and student advisors. This project is built using MkDocs, and the source files are in the `docs` directory.

### How to Contribute

1.  **Fork the repository:** Create your own copy of this repository to make changes.
2.  **Create a new branch:** Make your changes in a new branch.
3.  **Submit a pull request:** Once you are ready, submit a pull request for your changes to be reviewed.

### Feedback

For general feedback or suggestions, please open an issue in the repository.

## Getting Started (Local Development)

To run the course website locally, you will need to have Python and `uv` installed.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/businessmanagement101/businessmanagement101.github.io.git
    cd businessmanagement101.github.io
    ```

2.  **Install dependencies:**
    ```bash
    pip install uv
    uv sync
    ```

3.  **Run the local server:**
    ```bash
    uv run mkdocs serve
    ```

    The website will be available at `http://127.0.0.1:8000`.
